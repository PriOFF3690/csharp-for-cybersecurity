# CSharp for Cybersecurity

This repository documents my journey of learning C# and .NET with the goal of applying these skills to cybersecurity, networking, automation, and security tool development.

The projects in this repository cover fundamental C# programming concepts that form the foundation for building security-focused applications in the future.

---

## Learning Goals

- Learn C# programming fundamentals
- Understand the .NET ecosystem
- Master Object-Oriented Programming (OOP)
- Develop problem-solving and programming skills
- Build a strong foundation for cybersecurity tool development
- Explore networking, automation, and system programming with C#

---

## Project Structure

### HelloWorldApp
Introduction to C# application structure and console output.

### VariableDatatypeApp
Understanding variables, constants, and data types.

**Topics Covered**
- Variables
- Primitive Data Types
- Type Conversion
- Constants

### OperatorsApp
Working with different operators in C#.

**Topics Covered**
- Arithmetic Operators
- Relational Operators
- Logical Operators
- Assignment Operators

### ControlStatementsApp
Learning decision-making structures.

**Topics Covered**
- if Statements
- if-else Statements
- else-if Ladder
- switch Statements

### LoopControlsApp
Understanding repetitive execution using loops.

**Topics Covered**
- for Loop
- while Loop
- do-while Loop
- Nested Loops

### ConstructorsApp
Learning how objects are initialized.

**Topics Covered**
- Default Constructors
- Parameterized Constructors
- Constructor Overloading

### Classes&ObjectsApp
Introduction to Object-Oriented Programming concepts.

**Topics Covered**
- Classes
- Objects
- Fields
- Methods
- Encapsulation Basics
